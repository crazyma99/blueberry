# 静态资源说明

## 目录约束

源码静态资源只维护在 `src/static/`。页面和 `src/pages.json` 中按运行时路径 `/static/...` 或 `static/...` 引用。

## 现有资源

- `homepage.png`, `homepage-choosed.png` - 首页 TabBar 图标
- `pricelist.png`, `pricelist-choosed.png` - 价目表 TabBar 图标
- `mine.png`, `mine-choosed.png` - "我的" TabBar 图标
- `mine.svg` - 默认头像占位
- `like.svg`, `liked.svg` - 点赞图标
- `star.svg`, `starred.svg` - 收藏图标
- `search.svg` - 搜索图标

- `service.png` - 服务说明图片
- `price.png`, `honghe-price.png` - 本地价目表兜底图片
