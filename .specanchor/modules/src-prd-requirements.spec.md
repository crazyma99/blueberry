## 二、需求详情

### 3.1 新增用户登录

#### 需求描述

新增微信登录功能，支持用户授权登录。

#### 展示与交互

**登录触发时机**:
1. **用户进入小程序时**: 首次进入自动弹出登录弹窗
2. **点击收藏时**: 未登录用户点击收藏按钮会先触发登录
3. **我的页点击登录按钮**: 用户主动点击"立即登录"按钮

**未登录状态**:
- 我的页展示头像占位 + "点击立即登陆" 文案
- 可作为游客访问页面（点赞功能可用，基于 OAID 统计）

**登录交互**:
1. **点击登录按钮**:
   - 拉起微信授权弹窗
   - 用户点击"允许" → 复用微信头像和微信名称进行登录
   - 用户点击"不允许" → 不登录，但可作为游客访问页面

2. **已登录状态**:
   - 展示用户微信头像 + 昵称
   - 点击可拉起小程序登录浮窗，进行账号切换与管理

**游客模式限制**:
- 点赞功能: 可用（基于 OAID 统计）
- 收藏功能: 不可用（点击会先触发登录）

#### 技术实现

- 调用 `wx.login()` 获取 code
- 调用后端 `POST /api/wx/login` 接口换取 token
- 存储 token 和 userInfo 到本地 storage
- 登录状态全局共享（通过 `auth.uts`）

#### 接口依赖

- `POST /api/wx/login` — 微信登录（详见 `src-api-wechat.spec.md`）

### 3.2 新增我的页

#### 需求描述

新增"我的"页面，后续作为中台页承接未来所有 SaaS 服务售卖。

#### 展示与交互

**未登录状态**:
- 未登录头像（占位图）
- "立即登录" 按钮
- 推荐服务（金刚区）
- 活动 Banner（支持轮播，最多 3 张，5s/张切换）
- 联系我们区域

**已登录状态**:
- 用户微信头像 + 昵称
- 推荐服务（金刚区）
- 活动 Banner
- 联系我们区域

**交互**:
- 点击头像 + 立即登录 → 拉起小程序登录浮窗
- 点击金刚位 → 打开对应链接
- 点击 Banner → 打开对应链接

#### 数据结构

```typescript
data() {
  return {
    loading: true,
    userInfo: null,      // 用户信息（从 storage 读取）
    isLoggedIn: false,   // 登录状态
    banners: [],         // 活动 Banner 列表（来自 getPageConfig）
    menuItems: []        // 金刚区菜单（来自 getPageConfig）
  }
}
```

#### 接口依赖

- `auth.uts` — 获取登录状态和用户信息
- `wxLogin()` — 微信登录
- `getPageConfig()` — 获取金刚区配置和 Banner 配置

#### 页面路由

- **入口**: TabBar "我的"
- **出口**: 金刚区链接、Banner 链接

### 3.3 新增点赞与收藏功能

#### 需求描述

为客片展示增加点赞和收藏功能，支持账号维度/OAID 维度统计。

#### 客片列表页展示

**展示**:
- 点赞图标 + 点赞数（如 "55.9万"）
- 收藏图标（心形/星形）

**交互**:
- 点击点赞 → 展示点赞效果，再次点击取消点赞
- 点击收藏 → 展示收藏效果，再次点击取消收藏

**统计维度**:
- 点赞数: 用户账号维度统计
- 未登录用户点赞: 基于 OAID 统计（临时）
- 收藏: 仅登录用户可用，基于用户账号统计

#### 我的收藏页展示

**展示**:
- 顶部搜索栏（与设计稿一致）
- 我的收藏列表
- 客片展示（复用列表样式）

**交互**:
- 点击搜索框 → 拉起输入法，搜索收藏内容
- 点击搜索（键盘按钮）→ 展示搜索结果
- 点击客片展示 → 进入客片详情页

**备注**:
- 以设计稿为准，顶部是搜索栏
- 搜索空结果展示兜底文案

#### 技术实现

**点赞**:
- 调用 `POST /api/like` 进行点赞/取消点赞（toggle）
- 调用 `GET /api/like/status` 批量获取点赞状态和点赞数

**收藏**:
- 调用 `POST /api/favorite` 进行收藏/取消收藏（toggle）
- 调用 `GET /api/favorite/status` 批量获取收藏状态
- 调用 `GET /api/favorite/list` 获取我的收藏列表（支持门店筛选）

#### 接口依赖

- `POST /api/like` — 点赞/取消点赞
- `GET /api/like/status` — 批量查询点赞状态
- `POST /api/favorite` — 收藏/取消收藏
- `GET /api/favorite/status` — 批量查询收藏状态
- `GET /api/favorite/list` — 我的收藏列表

### 3.4 新增搜索功能

#### 需求描述

在客片列表页新增搜索功能，支持模糊匹配。

#### 展示与交互

**展示**:
- 搜索框（带搜索图标）
- 搜索按钮（虚拟键盘"搜索"按钮）

**交互**:
- 点击搜索框 → 拉起输入法
- 点击搜索（键盘按钮）→ tab 回到"全部"，展示搜索结果

**备注**:
- 搜索词支持模糊匹配
- 若搜索不到展示: "抱歉没有检索到您搜索的内容，请换个搜索词试试~"

#### 技术实现

- 搜索框使用 `input` 组件，监听 `@confirm` 事件（键盘搜索按钮）
- 调用 `GET /api/search` 接口进行搜索
- 搜索时隐藏 Tab 分类区域
- 支持分页加载

#### 接口依赖

- `GET /api/search?keyword=xxx&page=1&pageSize=10` — 搜索客片（支持分页）

### 3.5 加载中骨架优化

#### 需求描述

**问题**: 进入页面后由于网络问题等原因存在卡顿

**预期解决**: 降低进入卡顿体感

#### 技术方案

1. **统一骨架屏**:
   - 所有页面使用统一的骨架屏样式
   - 页面首次加载时展示骨架屏（Skeleton）
   - 骨架屏模拟页面基础布局结构（卡片、文字、图片占位）
   - 数据加载完成后替换为真实内容
   - 降低开发成本，保持视觉一致性

2. **Loading 提示**:
   - 使用 `uni.showLoading()` 展示全局 loading
   - 数据加载完成后调用 `uni.hideLoading()`

3. **分页加载**:
   - 上拉加载更多时底部展示 loading 指示器
   - 避免一次性加载大量数据

#### 实施范围

- 首页
- 价目表页
- 我的页
- 客片列表页
- 客片详情页
- 价目表详情页
- 我的喜欢页

### 3.6 主页&价格页优化改版

#### 3.6.1 展示样式优化

**问题**: 当前用户认为该区域不可点击，不知道怎么进入

**预期解决**: 增强用户点击欲望

**方案**:
- 店铺卡片增加点击态（hover 效果、阴影、边框等）
- 增加"点击进入"提示文案或箭头图标
- 优化卡片布局，使可点击区域更明显

#### 3.6.2 支持商家配置

**需求**: 支持商家图片配置后在主页、价格页进行展示

**实现**:
- 主页店铺列表使用 `/api/shops` 的 `homeImage` 字段
- 价格页店铺列表使用 `/api/shops` 的 `priceImage` 字段
- 动态渲染店铺名称（`displayName`）

#### 接口依赖

- `GET /api/shops` — 获取店铺列表

### 3.7 后台优化

#### 需求描述

**注意**: 后台管理系统是独立项目，不在小程序项目中实现。本 spec 仅记录需求供参考。

后台支持总管理、商户决策注册，支持模板创建，商户可对模板进行管理与内容上传。

#### 3.7.1 角色管理

**角色类型**:

| 角色类型 | 权限说明 |
|---------|---------|
| 超级管理员 | 支持对所有角色账号进行管理、门店模板进行创建 |
| 运营 | 支持对指定门店内容配置、支持对门店主页内容、中台内容进行配置 |
| 商家 | 支持对本门店内容进行配置 |

**权限控制**:
- 角色权限由后端控制
- 前端不需要根据角色动态展示/隐藏功能入口
- 所有权限控制由后端接口进行

**超级管理员**:
- 管理所有角色账号
- 创建和管理门店模板

**运营**:
- 绑定店铺（所有店铺 / 部分店铺）
- 配置指定门店内容

**商家**:
- 绑定店铺（支持多选）
- 配置本门店内容

#### 3.7.2 后台登录

- 账号密码登录
- 错误提示（账号错误、密码错误）
- 登录成功提示

#### 3.7.3 商家管理与模板创建

**店铺管理**:
- 店铺名称
- 外显名称（中英文）
- 展示顺序（数字，越大越靠前）
- 门店首页图（支持 jpg/png）
- 门店价格图（支持 jpg/png）
- 生效状态（生效/无效）

#### 3.7.5 中台页配置

**模块类型**:
- 金刚区
- Banner

**金刚区配置**:
- 业务名称（不外显）
- 资源名称（外显，上限 5 字）
- 图片（支持 png）
- 链接（跳转链接）
- 顺序（数字，越大越靠前）
- 生效状态

**Banner 配置**:
- 业务名称（不外显）
- 图片（支持 png）
- 链接（跳转链接）
- 顺序（数字，越大越靠前）
- 生效状态

**接口**:
- `GET /api/page-config` — 获取中台页配置（金刚区 + Banner）

## 九、注意事项

1. **向后兼容**: 新增功能不应影响现有功能
2. **游客模式**: 未登录用户可访问大部分功能，但点赞/收藏可能需要登录
3. **性能优化**: 骨架屏、分页加载、图片懒加载等优化用户体验
4. **数据安全**: 后台管理系统需要严格的权限控制
5. **打点准确性**: 确保埋点数据准确上报，避免重复或遗漏
