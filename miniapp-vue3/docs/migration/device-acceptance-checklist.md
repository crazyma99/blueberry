## 13. 弹层内按钮「触感 ＋ 按压」反馈一致性（2026-09-23 · 体验版 `v1.0.58`）

> 主人反馈：「Popup内的按钮缺少震动反馈和按压效果,一致性问题很严重。」
> 口径：**凡弹层内可点元素**＝按下时有**视觉按压反馈**（`.press-dim` 变淡）＋ 点击时**轻微振动**（`uni.vibrateShort({type:"light"})`，失败静默）。
> 说明：振动在 **iPhone 需系统设置里「声音与触感 → 触感」开启**；微信小程序内一般可用，且**平板/模拟器可能无马达**。

| # | 位置 | 看什么 |
|---|---|---|
| 13.1 | **上传照片质量拦截弹层**（AI 试衣/AI 推荐，上传不合格照片触发） | ⭐「重新选择照片」与「知道了」：按下**变淡**、点击**有轻微振动**（主人报的核心位置） |
| 13.2 | **登录弹窗** | 「一键登录」（已勾选协议时走微信手机号授权）与「暂不登陆」：按压＋振动；「协议勾选行」点按时有振动 |
| 13.3 | **资料完善弹窗** | 「确认」「跳过」与头像按钮：按压＋振动 |
| 13.4 | **门面按钮**（如 AI 试衣空态「重新加载」、推荐等待页「重试」） | 点击有轻微振动（门面统一加） |
| 13.5 | 自绘对话框（抖音端）/ 选择器 | 「取消/确定」有振动；选项行、选择器「清空」有按压＋振动（微信端选择器走 wot 组件，观感一致即可） |
| 13.6 | 全局观感一致性 | 对比「页面内按钮」与「弹层内按钮」：按压反馈与触感**不应有明显差别**（这正是本次修复目标） |
| 13.7 | 回归：正常下单/生成流程 | 振动不打断任何流程；不出现重复振动导致的连续震感（单次轻振） |
